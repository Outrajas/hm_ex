# Analysis-ready notebook copies

These copies preserve notebook code and Markdown while removing saved execution outputs and execution counters. Outputs often include long logs, rendered data, tables, or encoded images, which can make an ipynb much larger than its source code. The archived originals one directory above retain the outputs as downloaded from Drive.

The historical experiments_and _tests.ipynb source notebook is split into five review files so each is easier to upload and inspect. Every original cell is included exactly once and the original order is maintained across the numbered groups; the review copies are not standalone runnable notebooks.

- phase7_temporal_mano_training_progress_eta.ipynb — Phase 7 full training notebook, outputs removed.
- phase7_partial_cache_t4_training.ipynb — partial-cache training notebook, outputs removed.
- handtracker_dataset_acquisition.ipynb — acquisition notebook, outputs removed.
- experiments_history_part1_cells_00-14.ipynb and experiments_history_part2_cells_15-28.ipynb — early experiment revisions.
- phase0_phase1_cells_29-31.ipynb — unified Phase 0/1 runner and damped refiner diagnostic.
- phase2_diagnostics_cells_32-33.ipynb — Phase 2 diagnostics.
- phase3_mediapipe_cells_34-38.ipynb — MediaPipe/Sobel experiments.

These are review copies. Use the full snapshots in the parent directory when saved outputs or exact notebook state matter.
